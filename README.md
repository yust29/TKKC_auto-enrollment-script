# Class 1.0 — 自动选课脚本

基于 Python 的教务系统自动选课工具，用于厦门大学嘉庚学院（xujc）教务系统的自动抢课。

## 功能概述

- 自动扫描指定页码的课程列表，查找目标课程
- 发现**可选**的目标课程时自动提交选课请求
- 选课失败后自动循环重试，直到成功
- 每 6 次扫描后自动休息 40 秒，防止请求过于频繁被 ban
- 支持 Windows 系统通知（成功 / 异常提示）
- 脚本大部分由AI辅助完成，能用但存在一定bug，建议使用者具有一定检修能力

---

## 使用前需填写 / 修改的内容

使用本脚本前，你需要在 `class 1.0.py` 中检查和修改以下几个部分：

### 1. `target_courses`（第 41-46 行）⚠️ **必改**

```python
target_courses = [
    '沟通的艺术(MOOC)(1班) (职业技能类-职业技能类)',
    '沟通的艺术(MOOC)(2班) (职业技能类-职业技能类)',
    '组织行为与领导力(MOOC)(1班) (职业技能类-职业技能类)',
    '组织行为与领导力(MOOC)(2班) (职业技能类-职业技能类)',
]
```

将列表中的课程名称改为**你要抢的课程全名**。名称必须与教务系统网页上显示的完全一致（包括括号、空格等）。

> 💡 如何获取准确名称：在浏览器中打开选课页面，右键查看课程名称，直接复制即可。

### 2. `page_fetch_options`（第 49-56 行）⚠️ **按需修改**

```python
page_fetch_options = {
    1: False,
    2: False,
    3: True,    # 目标课程在第 3 页
    4: False,
    5: True,    # 目标课程在第 5 页
    6: False,
}
```

- `True` = 请求并扫描该页
- `False` = 跳过该页

请根据你的目标课程实际所在的页码调整。建议先手动在浏览器中确认目标课程在第几页。

### 3. `url`（第 12 行）⚠️ **必改**

```python
url = 'http://jw.xujc.com/student/index.php?c=Xk&a=List&id=1391'
```

这是选课列表页的 URL。不同学期 / 不同选课批次的 `id` 参数可能不同，请在浏览器中打开选课页面，复制完整 URL 替换此处。

### 4. cookies（第 30-35 行）

1. 用浏览器登录教务系统，进入选课页面
2. 按 `F12` 打开开发者工具 → 网络 → 随便点个按钮 → 找到index.php?c=Xk&a=List → 请求标头 → cookie
3. 将复制到的 cookie 内容填写到 `class 1.0.py` 的第 cookies 中
4. 除了 PHPSESSID 之外的内容仅需修改一次，PHPSESSID 会每日刷新，可在脚本启动时弹出的窗口中手动输入

> ⚠️ PHPSESSID 是登录凭证，请勿泄露给他人。

---

## 运行流程

1. 弹出 PHPSESSID 输入框 → 输入后点 OK
2. 脚本开始循环扫描课程页面
3. 每次请求间隔 5~7 秒（随机），防止触发频率限制
4. 找到可选目标课程后自动提交选课
5. 选课成功后弹出 Windows 通知并退出
6. 如果被系统限制访问，会弹出警告通知并终止

---

## 注意事项

- **不要**将请求间隔改得太短，否则可能被教务系统封禁 IP
- 脚本运行期间请保持网络畅通
- PHPSESSID 有时效性，如果脚本运行时间过长导致会话过期，需重新获取
- 每次扫描的页面内容会保存为 `response_pageX.html`，方便排查问题
- 本脚本仅用于学习交流，请合理使用，遵守学校相关规定
